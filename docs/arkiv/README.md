# Arkiv

Ferdige planer og arbeidsnotater. De beskriver hvordan appen ble til og hvorfor
valg ble tatt, men er **ikke** gjeldende dokumentasjon: koden kan ha endret seg
siden. Gjeldende kart over koden står i `AGENTS.md` i roten.

| Fil | Hva |
| --- | --- |
| `plan-lokal-app.md` | Planen for overgangen til en lokal app uten server og innlogging (september 2026). |
| `plan-taktikkbrett-5-funksjoner.md` | Planen for fem funksjoner på taktikkbrettet (september 2026). |
| `ryddeplan.md` | Plan og logg for oppdelingen av store filer (oktober 2026). |
| `ovelser/` | Arbeidsnotater fra gjennomgangen av øvelsene og kildene deres. Selve øvelsene ligger i `src/data/drills/`. |
